# G1 確認のお願い（おへや 段階1）

おへや 段階1（`feature/oheya`、版 v2.5.0）を、Mac と iPad で見てください。所要 30 分ほど（発熱の確認は約 10 分置いておくだけ）です。
判断（G1）はオーナーが行います。ここでは見てほしい点と、メモの欄をまとめます。

## 1. 準備（Mac、devcontainer の外のターミナル）
1. リポジトリのフォルダに移動して、作業ブランチにします。
   ```
   git fetch
   git switch feature/oheya
   ```
2. **Mac のブラウザだけで見る場合**（自分の Mac からしか見えません）：
   ```
   python3 -m http.server 8000 --bind 127.0.0.1
   ```
   ブラウザで `http://localhost:8000/` を開きます。
3. **iPad で見る場合**（同じ Wi-Fi 経由）：
   ```
   python3 -m http.server 8000
   ```
   Mac の IP アドレスを調べます：システム設定 → Wi-Fi → つながっているネットワークの「詳細…」→「IP アドレス」（例：192.168.1.23）。初回にファイアウォールの確認が出たら「許可」します。
4. 止めるときは Control＋C です。

> **注意**：`--bind` なしの `python3 -m http.server` は、そのフォルダ全体（`.git/` やローカルの設定ファイルも）を同じ Wi-Fi の端末に見せます。**家の信頼できる Wi-Fi でだけ行い、確認が終わったらすぐ Control＋C で止めてください。**

## 2. iPad で開く
1. iPad を Mac と同じ Wi-Fi にします。
2. Safari で `http://<MacのIP>:8000/` を開きます。
3. ホーム画面に追加して見る場合は、共有ボタン →「ホーム画面に追加」。

### データについて
- `http://<MacのIP>:8000` の育成データは、本番（GitHub Pages）とは**別の場所**に保存されます。本番の子どもの育成データはここには**ありません**（移りません）。まっさらな状態から始まります。
- 本番のデータを写して見たい場合（任意）：本番のアプリで「設定 → コードを表示・コピー」でバックアップコードを控え、確認用の画面で「設定 → 復元する」に貼り付けます。確認が終わったら、コードは消してください（人に見せない）。
- 確認用の画面で報告・エサやりをしても、本番には影響しません。

## 3. 見てほしいこと
- [ ] **昼と夜**：ひる／ゆうがた／よるで、まどの空と部屋の暗さが変わる。切り替わりがなめらかで、ちかちかしない（設定の寝る時刻を変えると夜を試せます）
- [ ] **夜**：ぷにが ラグの上で寝る（見ている間に夜になったら、歩いて寝に行く）
- [ ] **歩く感じ**：速さがちょうどよいか、速すぎ・遅すぎないか。止まったり、きょろきょろ・ぴょん・ダンスをしたりするか
- [ ] **向きを変える動き**：進む方へなめらかに体を向けるか。横顔・後ろ姿が不自然でないか
- [ ] **さわったとき**：さわっている間と はなした直後に、ぷにが指から逃げないか。エサのあとも少し止まるか。あたま・おなか・なでなで・ぎゅー・れんだ が今までどおり反応するか
- [ ] **ぷにの大きさ**：小さすぎないか、さわりやすいか
- [ ] **なめらかさと発熱**：約 10 分そのまま表示して、動きがカクカクしないか、iPad の背面があつくならないか（なし／ほんのり／あつい）
- [ ] **ホーム画面に追加**：アイコンから起動できる → ホームに戻る → 数分後に戻っても、部屋とぷにが描かれている
- [ ] **別のアプリを使ってから戻る**：同上
- [ ] **縦・横**：画面を回しても、部屋が収まり直す
