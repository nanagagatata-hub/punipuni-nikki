# G1 確認のお願い（おへやモード＋段階2）

おへやモード・こいん・おみせ・もようがえ（`feature/oheya`、版 v2.6.2）を、Mac と iPad で見てください。所要 40 分ほど（発熱の確認は約 10 分置いておくだけ）です。
判断（G1）はオーナーが行います。ここでは見てほしい点と、メモの欄をまとめます。

> 以前の版（v2.5.x）の「ホーム画面が おへや」は取りやめました。普段の画面は v2.4.0 と同じで、ヘッダーに「🪙 こいん」と「🏠 おへや」ボタンが増えただけです。おへやは、そのボタンから開く別の画面です。

## 1. 準備（Mac、devcontainer の外のターミナル）
1. リポジトリのフォルダに移動して、作業ブランチにします。
   ```
   git fetch
   git switch feature/oheya
   ```
2. **Mac のブラウザだけで見る場合**（自分の Mac からしか見えません）：
   ```
   python3 -m http.server 8000 --bind 127.0.0.1
   ```
   ブラウザで `http://localhost:8000/` を開きます。
3. **iPad で見る場合**（同じ Wi-Fi 経由）：
   ```
   python3 -m http.server 8000
   ```
   Mac の IP アドレスを調べます：システム設定 → Wi-Fi → つながっているネットワークの「詳細…」→「IP アドレス」（例：192.168.1.23）。初回にファイアウォールの確認が出たら「許可」します。
4. 止めるときは Control＋C です。

> **注意**：`--bind` なしの `python3 -m http.server` は、そのフォルダ全体（`.git/` やローカルの設定ファイルも）を同じ Wi-Fi の端末に見せます。**家の信頼できる Wi-Fi でだけ行い、確認が終わったらすぐ Control＋C で止めてください。**

> **別の見方**：claude.ai 上の非公開のプレビュー用ページのリンクを、別途お渡しします。サーバーを立てずに、ブラウザだけでおへやの見た目や操作を試せます（リンクは人に見せないでください）。**プレビュー用ページには、本番のバックアップコード（復元コード）や本番の育成データを貼り付けないでください。** プレビューは まっさらな状態で試すためのものです。

## 2. iPad で開く
1. iPad を Mac と同じ Wi-Fi にします。
2. Safari で `http://<MacのIP>:8000/` を開きます。
3. ホーム画面に追加して見る場合は、共有ボタン →「ホーム画面に追加」。

### データについて
- プレビューや `http://localhost:8000`・`http://<MacのIP>:8000` の育成データ（こいん・家具・部屋の配置も）は、本番（GitHub Pages）とは**別の場所**に保存されます。本番の子どもの育成データはここには**ありません**（移りません）。まっさらな状態から始まります。
- ここで報告・エサやり・買い物・もようがえをしても、本番には影響しません。逆に、本番のデータにここでの こいんや家具が入ることもありません。
- 本番のデータを写して見たい場合（任意。`http://localhost:8000`・`http://<MacのIP>:8000` だけで行い、プレビュー用ページには貼らない）：本番のアプリで「設定 → コードを表示・コピー」でバックアップコードを控え、確認用の画面で「設定 → 復元する」に貼り付けます。確認が終わったら、コードは消してください（人に見せない）。

## 3. 試すための こいんの増やし方
本番のこいんは 0 から始まり、報告で 1〜3 ずつしか増えません（エサの pt と同じ）。おみせを試すには、確認用の画面で次のどちらかをしてください。
- **報告を重ねる**：「できたこと」のボタンを押すと、エサの pt と同じだけ こいんが増えます（にくまん 3、くっきー・ぱん 2、ほかは 1 など。ぐんぐんたいむの倍率はなし）。1 日の上限があるので、増えるのはゆっくりです。
- **テスト用の こいんを入れる**（確認用の画面だけ）：ブラウザの開発者ツールのコンソール（Mac の Safari なら「開発」メニュー → 「Webインスペクタ」）で、保存データの `coin` を書き換えて再読み込みします。
  ```
  const k='punipuni-nikki-v2'; const d=JSON.parse(localStorage.getItem(k)); d.coin=500; localStorage.setItem(k,JSON.stringify(d)); location.reload();
  ```
  こいんは 0〜999999 の範囲で読み込まれます。**本番の画面では行わないでください。**

## 4. 見てほしいこと

### 4.1 おへやモード
- [ ] 普段の画面は今までどおり。ヘッダーに「🪙 数字」「📚 ずかん」「🏠 おへや」が並び、はみ出さない
- [ ] 「🏠 おへや」で全画面の おへやが開く。「← もどる」で普段の画面に戻る。エサやり・報告は おへやではできない（普段の画面だけ）
- [ ] **昼と夜**：ひる／ゆうがた／よるで、まどの空と部屋の暗さが変わる。切り替わりがなめらかで、ちかちかしない（設定の寝る時刻を変えると夜を試せます）
- [ ] **夜**：ぷにが ラグの上で寝る（見ている間に夜になったら、歩いて寝に行く）
- [ ] **歩く感じ**：速さがちょうどよいか。家具を避けて歩き、家具の後ろに回るか。止まったり、きょろきょろ・ぴょん・ダンスをしたりするか
- [ ] **向きを変える動き**：進む方へなめらかに体を向けるか。横顔・後ろ姿が不自然でないか
- [ ] **なでる**：あたま・おなか・なでなで・ぎゅー・れんだ が、普段の画面と同じように反応するか。さわっている間と はなした直後に、ぷにが指から逃げないか
- [ ] **ぷにの大きさ**：小さすぎないか、さわりやすいか
- [ ] **縦・横**：画面を回しても、部屋全体が画面に収まる

### 4.2 こいん
- [ ] 報告すると、ヘッダーの こいんが エサの pt だけ増える（にくまん 3 など）。ぐんぐんたいむ中でも倍にならない
- [ ] 報告を取り消すと、こいんが戻る
- [ ] 再読み込みしても こいんが残る。0 から始まり、遡って増えていない

### 4.3 おみせ（おへやの「🛒 おみせ」）
- [ ] タブ「かぐ」「ゆか」「かべ」「ひろげる」が切り替わり、絵・なまえ・ねだんが見える。ひらがなだけで読める
- [ ] こいんが足りないカードは、うすく表示されて押せない（「あと 🪙 N」）
- [ ] 買うと「これを かう？」が出て、「かう」で こいんが減る。かぐは もちもの に入り、ゆか・かべは すぐ部屋に反映される
- [ ] 「ひろげる」で 6→8→10 と部屋が広がり、家具の位置が変わらない
- [ ] 値段が高すぎ・安すぎないか（値段は案です。全部そろえて 665 こいん）

### 4.4 もようがえ（おへやの「🛠 もようがえ」）
- [ ] かぐを選び、置きたい マスを押すと置ける。置ける マスは みどり、置けない マスは あか
- [ ] 置いた家具を選んで別の マスを押すと動く。「まわす」で向きが変わる。「しまう」で もちものに戻る
- [ ] ぷにのいる マスに置くと、ぷにが となりへ移る
- [ ] 高い家具の後ろの マスが押しにくくないか（編集中は家具が半透明になります）
- [ ] 「おわり」で戻ると、また なでられる。再読み込みしても配置が残る
- [ ] 家具の絵（17 しゅるい）・ゆか・かべが かわいいか、見分けがつくか

### 4.5 なめらかさと発熱
- [ ] 約 10 分、おへやを表示したままにして、動きがカクカクしないか、iPad の背面があつくならないか（なし／ほんのり／あつい）。家具を多く置いた状態（20〜30 個）でも試す
- [ ] **ホーム画面に追加**：アイコンから起動できる → 起動は普段の画面 → おへやを開ける。別のアプリを使ってから戻っても、おへやが描かれている

## 5. 今わかっている限界（気づいたら教えてください）
- 後ろ姿はのっぺりしています（しっぽなどは足していません。子どもの反応を見て決めます）。
- シークレット（にじ色）は、おへやの中では色が回らず、止まった にじ色です。
- あせ（しずく）や Z の記号は、後ろ姿のときも表示されたままです。
- 家具の向きは、左右を反転して表します（まわすと、影の明るさが左右で入れ替わります）。
- 家具を使う行動・ランプの明かり・ずかんの子を呼ぶ機能は、まだありません。
- Canvas が使えない場合は、おへやは開かず「おへや を ひらけなかったよ」と出ます（普段の画面は使えます）。
