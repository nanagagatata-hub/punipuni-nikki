## 一生
- しきい値：たまご 0 → あかちゃん **3** → こども **10** → おとな **25**（累計 pt）
- おとな → **さいごのすがた**（stage 4）：`adultAt` の日付 +2 日の起きる時刻以降
- おわかれ：`finalSeenAt`（さいごのすがた のモーダルを閉じた時）の日付 +1 日の 6:00 以降・夜でない・病気でない時にキャラをタッチ → あいさつ 3 ページ → たまごを受け取る → 次の世代
- 引き継ぐ：なまえ、よびかた、gen+1、zukan・shinySeen・history、lessonDays、inv、day/cnt、boostUntil、sound、cfg、tempNight

## 分岐（ずかん 19 種）
- あかちゃん（最大のつよさ）：ka ぷにぷに / ki しずく / ge ころ / ho もこ
- こども（最大のつよさ）：ka ほし / ki しゃぼん / ge はな / ho くも
- おとな 11 種：全 >0 かつ `max/min ≦ 1.6` → にじ ／ 2 位 ≧ 1 位×0.75 → 2つ型（つきみ ka+ki・ぼうけん ka+ge・ゆめみ ka+ho・まりん ki+ge・けーき ki+ho・おひさま ge+ho）／ それ以外 → 1つ型（はかせ・きらら・もりもり・ぽかぽか）
- おとなは ずかん に無いものを優先（相性スコア順）。11 種そろったら第1候補の **きらきら色違い**
- 同値は ka→ki→ge→ho 優先

## 時間と状態
| 項目 | 値 |
|---|---|
| 時間帯 | あさ 起きる時刻–9 / ひる 10–15 / ゆうがた 16–寝る時刻 / よる（ねんね） |
| ねんね | 設定の寝る〜起きる時刻（初期 20:00〜6:00）。減少停止・寝顔・エサ不可・タッチしても起きない。設定で許可すると「ちょっとだけ おきて」で 5 分起きる（ひと晩 1 回） |
| おなか / ごきげん | 0〜4、初期 3。起きている 3h / 4h ごとに −1 |
| 病気 | おなか 0 が起きている時間で 3h 続くと発症 → エサ 2 つで回復。病気中は成長しない |
| タッチ | あたま（上 40%）・おなか・なでなで（80px）・ぎゅー（700ms）・れんだ（2.5 秒に 5 回）。ごきげん +1 は 30 分に 1 回 |
| 表情 | ねんね ＞ 病気 ＞ リアクション（2.5 秒）＞ おなか×ごきげん の 9 通り |
| ひとりごと | 起きていて 90 秒操作なしで 1 回 |
| 更新間隔 | 起動時・30 秒ごと・前面復帰時 |
| たまご期 | 時間経過なし。エサで pt・パラメータは入る |

## データ
- 保存先：`localStorage['punipuni-nikki-v2']`、形式 `v:2`（無ければ v1 のキー `punipuni-nikki-v1` を読んで移行。v1 キーには書かない。壊れたデータは `-broken` に退避）
- バックアップ：出力 `PUNI2:`、入力 `PUNI1:`/`PUNI2:`、Base64(UTF-8 JSON)、40,000 文字まで
- 読込・復元は必ず `sanitize()`（`js/state.js`）を通す。キー追加時は `DEF()` と `sanitize()` 両方
- `APP_VERSION`（`js/app.js`）と `VERSION`（`sw.js`）は同じ値

## 変更前チェックリスト

- [ ] なまえ・よびかた・history を `innerHTML` に入れるなら `esc()`
