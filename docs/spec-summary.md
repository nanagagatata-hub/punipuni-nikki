## 進化
- しきい値：たまご 0 → あかちゃん **3** → こども **10** → おとな **25**（累計 pt）
- あかちゃん = ぷにぷに
- こども：`ka+ki ≧ ge+ho` → ほしぷに ／ それ以外 → はなぷに
- おとな：全 >0 かつ `max/min ≦ 1.6` → **にじぷに** ／ それ以外は最大値で はかせ(ka)・きらら(ki)・もりもり(ge)・ぽかぽか(ho)（同値は ka→ki→ge→ho 優先）
- ずかん 8 種（たまご除く）

## 時間と状態
| 項目 | 値 |
|---|---|
| ねんね（減少停止） | 21:00〜6:59 |
| おなか / ごきげん | 0〜4、初期 3。起きている 3h / 4h ごとに −1 |
| なでる | ごきげん +1（30 分に 1 回）。病気中は無効 |
| 病気 | 最後のエサから起きている 12h で発症 → エサ 2 つで回復。病気中は成長しない |
| 寝顔表示 | 夜間 かつ 無操作 2 分 |
| 更新間隔 | 起動時・30 秒ごと・前面復帰時 |
| たまご期 | 時間経過なし。エサで pt・パラメータは入る |

## つぎのたまご
- 引き継ぐ：gen+1、zukan、lessonDay、inv、day/cnt、boostUntil
- リセット：それ以外すべて（**なまえも初期値に戻る**）

## データ
- 保存先：`localStorage['punipuni-nikki-v1']`、形式 `v:1`
- バックアップ：`PUNI1:` + Base64(UTF-8 JSON)、20,000 文字まで
- 読込・復元は必ず `sanitize()` を通す。キー追加時は `DEF()` と `sanitize()` 両方

## 変更前チェックリスト
- [ ] UI 文言はひらがなのみ（設定画面は漢字可）
- [ ] インライン script / `style=""` / `onclick=""` なし、外部通信なし（CSP は `'self'` のみ）
- [ ] なまえ等を `innerHTML` に入れるなら `esc()`
- [ ] 保存キーを増やしたら `sanitize()` に追加、形式変更なら移行処理
- [ ] キャラは死なない・罰なし・オリジナルデザイン
- [ ] `node --check js/app.js` → Playwright で起動・エサやり・設定・保存/復元・コンソールエラー確認
- [ ] `sw.js` の `ASSETS` 対象を変えたら `VERSION` を上げる
- [ ] 仕様を変えたら `spec.md` と本書を更新
