## 1. 概要

| 項目 | 内容 |
|---|---|
| 目的 | 現実の習慣（中国語・歯みがき・野菜・お風呂・お片付け・早寝・早起き）を報告 → エサをもらう → 育てる、で習慣づけを楽しくする |
| 利用者 | 娘（ひらがなのみ読める）。設定画面のみ保護者 |
| 端末 | iPad Safari（ホーム画面に追加して standalone 起動）。PC ブラウザでも動作 |
| 形態 | 静的サイト（HTML/CSS/JS の ES モジュール、依存ライブラリなし、ビルドなし） |
| 通信 | 外部通信なし。CSP で `'self'` のみ許可。音は端末内で合成 |
| 保存 | 端末の `localStorage`（キー `punipuni-nikki-v2`、形式 `v:2`。v1 のキーは移行のため読むだけ） |
| 子ども向け配慮 | キャラは死なない。罰はなく「お世話で回復する」設計。一生の終わりは「たびだち」としてたまごを託す |

### 基本ループ
```
現実でタスクをする → 「できたこと を おしえてね」で報告（「できた？」確認）
  → エサがトレイに入る → エサをタップしてあげる（ねんね中は不可）
  → ポイント・パラメータ上昇 → しきい値で進化 → おとな（2〜3日）
  → さいごのすがた（1日）→ おわかれ → たまごを受け取って次の世代
```

- レイアウト：iPad（幅・高さとも 700px 以上）は 1 画面に収める（`100dvh`、スクロールなし）。キャラの絵が残りの高さに合わせて伸び縮みする。縦は 1 カラム（キャラ → できたこと → つよさ）、横は 2 カラム（左：キャラ、右：できたこと・つよさ）。iPad mini 縦 744×1109〜1133・横 1133×720〜744 で確認。それより小さい画面は縦スクロール。
- 見た目：絵本のページ風。あたたかいピーチベージュの背景（`#F2DCC6`）に、白に近い紙色のカード（ふち＋下の影で立体的に）。ぷにちゃんの額は手ぬい風の点線。端末がダークモードでも明るい色のまま（`color-scheme: light`）。
- 動き（マイクロインタラクション）：
  - ボタン・タイル・エサは押すと ぷにっとへこみ、はなすと ぽよんと戻る
  - できたこと：💮 のスタンプ、タイルから星とハートがはじける、もらったエサがトレイに ぽんと出る
  - エサ：トレイからぷにちゃんへ飛んでいく。ふえたゲージが ぼよん、せいちょうバーが きらっ
  - 吹き出し：しゃべると ぽよん。モーダル：下から ぽよんと出る。しんか：うしろで光が回り、紙ふぶき
  - ずかん：じゅんばんに ぽん
  - まっている間：ぷにちゃんのまばたき、ずかんボタンがときどき ゆれる、💌 と「ちょっとだけ おきて」がふわふわ光る
  - 端末の「視差効果を減らす」が有効なときは、すべての動きを止める

## 3. タスクとエサ

### 3.1 タスク一覧
| id | 表示名 | 上限 | 受付 | もらえるエサ |
|---|---|---|---|---|
| `lesson` | ちゅうごくご れっすん | 1日1 | 設定の曜日（最大 2 つ、初期値：土曜）のみ | にくまん 🥟 |
| `jishu` | ちゅうごくご じしゅう | 1日1 | いつでも | ことばのみ 🍒 |
| `hamigaki` | はみがき | あさ 1（0:00〜14:59）・よる 1（15:00〜23:59） | いつでも | きらきらあめ 🍬 |
| `yasai` | おやさい | 1日3 | いつでも | やさいすーぷ 🥣 |
| `ofuro` | おふろ | 1日1 | いつでも | あわあわぷりん 🍮 |
| `katazuke` | おかたづけ | 1日1 | いつでも | ぴかぴかくっきー 🍪 |
| `dryer` | どらいやー | 1日1 | いつでも | ふわふわきゃんでぃ 🍭 |
| `hayane` | はやく べっどに はいれた | 1日1 | 設定（初期：18:00〜。日〜木は 20:00、金・土は 21:00 で締め切り。締め切りは曜日ごと） | ほっとみるく 🥛 |
| `hayaoki` | はやおき | 1日1 | 設定（初期：月〜金の 5:00〜7:00 の前まで。時刻は全曜日共通、曜日は選択） | おひさまぱん 🍞 |

- 報告時は確認モーダル「◯◯ できた？」を出し、「できた！」でエサを 1 つトレイに追加（ねんね中でも報告できる。エサは朝にあげる）。
- **取り消し（もどす）**：まちがえて報告したときは、そのタイルをもう一度押すと「まちがえちゃった？」→「↩️ もどす」で取り消せる（まだ報告できるタスクでは「できた？」の画面に「↩️ まちがえた（もどす）」が出る）。
  - 条件：その日の報告で、そのタスクでもらったエサがまだトレイにあること（ご飯をあげる前）。
  - 最後の 1 回分の回数とエサを 1 つ戻す。れっすん は ぐんぐんたいむ も報告前に戻す。
  - 日付が変わると取り消せない（取り消し用の記録 `undo` を消す）。
- レッスンを報告すると **ぐんぐんたいむ** 開始（報告時刻から 24 時間）。再報告で「その時点から 24 時間」に上書き。
- 受付時間外の説明文：れっすん「◯ようび と ◯ようび だけ」、はやね「18じ から」／「きょうは おしまい」、はやおき「へいじつ あさ 5じ〜7じ」。
- 注意：0:00〜5:59 のはみがきは その日の「あさ」枠として数えられる。

### 3.2 日付リセット
- 端末ローカル時刻の日付（`YYYY-M-D`）が変わったら当日の回数 `cnt` をクリア。
- 未使用のエサ（`inv`）は持ち越し。上限なし（保存時は各 999 まで）。

| エサ | ポイント | パラメータ | おなか | ごきげん | 備考 |
|---|---|---|---|---|---|
| にくまん 🥟 | 3 | かしこさ +3 | +2 | — | 中国語を話す |
| ことばのみ 🍒 | 1 | かしこさ +1 | +1 | — | 中国語を話す |
| きらきらあめ 🍬 | 1 | きれい +1 | +1 | — | |
| やさいすーぷ 🥣 | 1 | げんき +1 | +1 | — | |
| あわあわぷりん 🍮 | 1 | ほかほか +1 | +1 | +1 | |
| ぴかぴかくっきー 🍪 | 2 | きれい +2 | +1 | — | |
| ほっとみるく 🥛 | 1 | ほかほか +1 | +1 | — | |
| おひさまぱん 🍞 | 2 | げんき +2 | +1 | — | |

- ぐんぐんたいむ中は **ポイントとパラメータのみ 1.5 倍**。おなか・ごきげんは倍にならない。
- おなか・ごきげんの上限は 4。たまご期はおなか・ごきげんは変化しないが、ポイントとパラメータは加算される。
- ねんね中（設定の寝る時刻〜起きる時刻、初期 20:00〜6:00）はエサをあげられない（「すやすや… あさ に たべるね」、エサは減らない）。

- エサを食べると、おなか 0 の積算 `zeroAcc` を 0 に戻す。

## 4. 一生と進化

### 4.1 段階
| stage | 段階 | 到達条件 |
|---|---|---|
| 0 | たまご | 初期 |
| 1 | あかちゃん | 累計 3pt |
| 2 | こども | 累計 10pt |
| 3 | おとな | 累計 25pt。時刻を `adultAt` に記録 |
| 4 | さいごの すがた | `adultAt` の日付 + 2 日の、起きる時刻以降（おとな期間 2〜3 日）。夜は変化しない。時刻を `finalAt` に記録 |

- エサをあげた後に判定。1 回で複数段階を越える場合は、進化モーダルを閉じるたびに次の進化が続く。
- たまご → あかちゃん時に、おなか・ごきげんを 3 に、時間経過の積算をリセット。
- さいごのすがた の進化モーダルを閉じた時刻を `finalSeenAt` に記録。モーダルを閉じずにアプリを閉じた場合は、次に昼間開いた時にもう一度出す。

### 4.2 おわかれ
- 条件：stage 4、`finalSeenAt` の日付 + 1 日の、起きる時刻以降、ねんね帯でない、病気でない。条件を満たすとバッジ 💌。
- 病気中にタッチすると「げんきに なったら おはなし したいな」。
- キャラをタッチ → 3 ページのあいさつ（よびかた を設定していれば呼びかける）→「これ、◯◯ に わたすね。つぎの こ を よろしくね」→「うけとる」で次の世代。
- `history` に `{f: 姿, n: なまえ, g: 何ひきめ, s: 色違い}` を追加（最新 200 件）。
- 引き継ぐもの：なまえ、よびかた、世代数 +1、ずかん・色違い・`history`、レッスン曜日、所持エサ、当日の日付と回数、ぐんぐんたいむ、音の設定、生活リズムの設定（`cfg`・`tempNight`）。それ以外は初期化。

### 4.3 進化先（進化する瞬間のパラメータで判定。同値は かしこさ→きれい→げんき→ほかほか の順で先を優先）
| 進化 | 決め方 | 進化先 |
|---|---|---|
| たまご → あかちゃん | 最大のつよさ | かしこさ ぷにぷに（`puni`）／きれい しずくぷに（`shizuku`）／げんき ころぷに（`koro`）／ほかほか もこぷに（`moko`） |
| あかちゃん → こども | 最大のつよさ | かしこさ ほしぷに（`hoshi`）／きれい しゃぼんぷに（`shabon`）／げんき はなぷに（`hana`）／ほかほか くもぷに（`kumo`） |
| こども → おとな | 下記 | 11 種 |

おとなの決め方：
1. 第1候補：4 つすべて > 0 かつ 最大/最小 ≦ 1.6 → にじぷに（`niji`）。そうでなく 2 位 ≧ 1 位 × 0.75（かつ 2 位 > 0）→ 上位 2 つの 2つ型。それ以外 → 1 位の 1つ型。
2. 残りのおとなを相性スコア順に並べる（1つ型 X：`v[X]`、2つ型 XY：`(v[X]+v[Y])/2`、にじ：`最小値 × 1.6`。同点は ずかん順）。
3. 第1候補から順に、ずかん にまだ無い最初のおとなにする（1 度出たおとなは出ない）。
4. 11 種すべて ずかん にある場合は、第1候補の **きらきら色違い**（`shiny`）。

| 型 | おとな |
|---|---|
| 1つ型 | はかせぷに（かしこさ）・きららぷに（きれい）・もりもりぷに（げんき）・ぽかぽかぷに（ほかほか） |
| 2つ型 | つきみぷに（かしこさ＋きれい）・ぼうけんぷに（かしこさ＋げんき）・ゆめみぷに（かしこさ＋ほかほか）・まりんぷに（きれい＋げんき）・けーきぷに（きれい＋ほかほか）・おひさまぷに（げんき＋ほかほか） |
| バランス | にじぷに |

### 4.4 見た目
- すべてオリジナルデザイン（既存キャラの模倣禁止）。共通の体に、耳（あかちゃんは耳なし・少し小さい）・体色・アクセサリで描き分ける。
- さいごのすがた：体のうしろにパステルの虹のオーラ、きらきら（天国を連想させる羽・光の輪は使わない）。名前は「かがやく ◯◯」。
- 色違い：体がパステル虹のグラデーション＋✨。名前は「きらきら ◯◯」。
- たまごはポイント 2 以上でヒビが入る。

### 4.5 ずかん
- 進化で新しい姿になった時に登録（たまごは対象外）。見出し「ずかん（発見数 / 19）」、あかちゃん・こども・おとな の小見出し。
- 未発見は灰色シルエット＋「？？？」＋ヒント。
- おとなの欄：その姿で旅立った子がいれば 🌈 と「なまえ・◯ぴきめ」（最新 1 件）、ほかにいれば「ほか ◯ひき」。色違いを見ていれば ✨。

## 5. 状態と時間経過

### 5.1 時間帯
| 帯 | 時刻 | 用途 |
|---|---|---|
| あさ | 起きる時刻〜9:59 | 背景・あいさつ・ひとりごと |
| ひる | 10:00〜15:59 | 同上 |
| ゆうがた | 16:00〜寝る時刻 | 同上 |
| よる（ねんね） | 寝る時刻〜起きる時刻（初期 20:00〜6:00） | 背景・ねんね |

- **ちょっとだけ おきて**：設定で許可していると、ねんね中にバッジの位置へボタンが出る。押すと 5 分間（`tempUntil`）起きていて、エサ・タッチがふだんどおりできる。ひと晩 1 回（`tempNight` に その夜の日付。起きる時刻より前は前日の夜）。時間経過・さいごのすがた・おわかれは夜として扱う。

- ねんね中は時間経過による減少・病気の進行が止まる。寝顔・「💤 ねんね ちゅう」。タッチすると「むにゃむにゃ…」系の反応だけで起きない。
- 経過時間は 5 分刻みで「起きている時間」だけを積算（最大で直近 40 日ぶん）。
- 判定タイミング：起動時、30 秒ごと、アプリが前面に戻った時（`visibilitychange`）。
- たまご期は時間経過の影響を受けない。

### 5.2 ゲージ（0〜4、初期値 3）
| ゲージ | 減り方 | 増やし方 |
|---|---|---|
| おなか 🍙 | 起きている時間 3 時間ごとに −1 | エサ（にくまん +2、他 +1） |
| ごきげん 🌸 | 起きている時間 4 時間ごとに −1 | タッチ（30 分に 1 回だけ有効 +1）、あわあわぷりん +1 |

### 5.3 びょうき
- 発症：おなか 0 の状態が、起きている時間で 3 時間続く（`zeroAcc`）。
- 症状：表情 `sick`、バッジ「🤒 びょうき：ごはん あと N こ で なおる」、タッチしても ごきげん は上がらない。
- 回復：エサを 2 つ（種類は問わない）。病気中はエサでポイント・パラメータが増えない。

### 5.4 表情とポーズ
- 優先順：ねんね ＞ びょうき ＞ リアクション中（2.5 秒）＞ おなか×ごきげん。
- おなか段階：0＝ぺこぺこ、1〜2＝すこし、3〜4＝まんぷく。ごきげん段階：0〜1＝しょんぼり、2〜3＝ふつう、4＝るんるん。

| おなか＼ごきげん | しょんぼり | ふつう | るんるん |
|---|---|---|---|
| まんぷく | すねる（傾き） | にこにこ（ゆれる） | きらきら（ぴょんぴょん） |
| すこし | しょんぼり（うなだれ） | ふつう | にこにこ（ゆれる） |
| ぺこぺこ | なみだ（うなだれ） | おなかを押さえる（🍙 を思い浮かべる） | よだれ（🍙） |

- `prefers-reduced-motion` ではアニメーションを止める。

## 6. タッチ
| 操作 | 判定 | 反応 |
|---|---|---|
| あたま タップ | 上 40% をタップ | 照れ顔・「えへへ」系 |
| おなか タップ | それ以外をタップ（キーボード操作もこれ） | 笑い顔・「くすぐったい」系・笑い声 |
| なでなで | 押したまま合計 80px 以上動かす | 目を細める・**鳴き声** |
| ぎゅー | 700ms 以上ほぼ動かさず押す | 「ぎゅー！」・ハグの音 |
| れんだ | 2.5 秒以内に 5 回タップ | 目がぐるぐる・回転 |

- ごきげん +1 はどの操作でも 30 分に 1 回。こども以上の あたま／おなか タップでは 30% で中国語を話す。
- たまご期：ころころ反応のみ。病気中：「ごはん たべたら げんきに なるかも」。ねんね中：§5.1。おわかれ準備中：おわかれを開始。

## 7. 音
- 効果音・鳴き声は Web Audio API で合成（音声ファイルなし）：ボタン、タスク報告、食事、進化、回復、なでなで（鳴き声 3 種）、笑い声、ぎゅー、れんだ、寝息、たまご、おわかれ。
- iPad の自動再生制限のため、操作のたび（`pointerdown`・`pointerup`・`touchend`・`click`）に `AudioContext` の作成・再開を試みる。
- 🔊：Web Speech API で吹き出しの日本語（`ja-JP`、pitch 1.7、rate 1.05）→ 中国語（`zh-CN`、pitch 1.3、rate 0.85）の順に読み上げ。
- 設定の「音：オフ」で効果音・鳴き声・読み上げをすべて止める。非対応端末では何もしない。

## 8. セリフと中国語
- セリフは `js/data.js` の `LINES`。あいさつ・ひとりごとは時間帯ごと、ひとりごとは状態（おなか 0・しょんぼり・ご機嫌）でも変わる。`{you}` を含む文は よびかた を設定した時だけ使う。
- あいさつ：起動時と、30 分以上たって前面に戻った時。ひとりごと：起きていて、モーダルが無く、90 秒操作がない時に 1 回。
- 中国語：単語 35 語＋短い文 28 文（`WORDS`・`PHRASES`、`[簡体字, ひらがな読み, いみ]`）。吹き出しは「◯◯「よみ」は ちゅうごくごで「いみ」だよ！」＋簡体字。単語と短い文は半々。

## 9. おうちの方の設定（⚙️ 1 秒長押し）
文言は漢字可。

| 項目 | 仕様 |
|---|---|
| なまえ | 最大 8 文字。空欄なら変更しない |
| よびかた | お子さんの呼び名、最大 8 文字。空欄なら呼びかけない |
| 中国語レッスンの曜日 | 1 つめ（日〜土）＋ 2 つめ（なし／日〜土）。同じ曜日なら 1 つにまとめる |
| 音 | オン／オフ |
| ぷにちゃんが寝る・起きる時刻 | `<input type="time">`（5 分刻み）。寝る 18:00〜23:30、起きる 4:00〜9:00 |
| はやおき | 受付の開始・終了時刻（全曜日共通）と曜日（チェック） |
| はやね | 受付の開始時刻と、日〜土それぞれの締め切り時刻 |
| ちょっとだけ おきて | ボタンを出す／出さない（初期：出さない） |

- 生活リズムの時刻は保存前に `cleanCfg` と同じ検証をし、範囲外や「終わり ≦ 始まり」があれば生活リズムだけ保存せずトーストで知らせる（ほかの設定は保存する）。
| アプリを更新する | Service Worker に更新を確認させ、新しい版の有効化を最大 8 秒待ってから再読み込み（失敗しても再読み込み）。現在の版を表示 |
| コードを表示・コピー | `PUNI2:` のバックアップコードを表示し、クリップボードへコピー |
| コードから復元 | `PUNI1:`／`PUNI2:` を検証し、2 回タップで置き換え（1 回目は「今のデータを置き換えます。もう一度タップ」）。失敗時「コードが正しくありません…」 |
| 最初からやり直す | 2 回タップで全データ初期化（ずかん含む） |

## 10. データ

### 10.1 保存
- `localStorage['punipuni-nikki-v2']` に JSON で保存（形式 `v:2`）。操作のたび・30 秒ごとに保存。
- 読み込み：`punipuni-nikki-v2` → 無ければ v1 の `punipuni-nikki-v1`（移行）。v1 のキーには書き込まない（古い版のタブが残っていても v2 のデータを上書きされない）。
- 読み込み失敗・不正データ時は、元の文字列を `punipuni-nikki-v2-broken` に退避してから初期データで開始。
- 起動時に `navigator.storage.persist()` を要求。

### 10.2 保存形式（`v:2`）
| キー | 型 | 初期値 | 検証（`sanitize()`） |
|---|---|---|---|
| `v` | 2 | 2 | 1 は移行、それ以外は拒否 |
| `name` | string | `ぷにちゃん` | trim・8 文字。空なら初期値 |
| `you` | string | '' | trim・8 文字 |
| `gen` | int | 1 | 1〜9999 |
| `stage` | int | 0 | 0〜4 |
| `form` | string | `egg` | `FORMS` のキーで段階に合うもの。合わなければ 1:`puni`、2:`hoshi`、3/4:`hakase` |
| `shiny` | bool | false | stage ≧ 3 の時のみ |
| `pts`・`p.{ka,ki,ge,ho}` | number | 0 | 0〜1e6 |
| `hunger` / `mood` | int | 3 | 0〜4 |
| `hAcc` / `mAcc` / `zeroAcc` | ms | 0 | 0〜1e10 |
| `sick` | bool | false | `true` のみ真 |
| `cure` | int | 0 | 0〜2 |
| `lastTick` / `petAt` | ms | 現在 / 0 | 0〜現在 |
| `boostUntil` | ms | 0 | 0〜現在+24h |
| `adultAt` / `finalAt` / `finalSeenAt` | ms | 0 | 0〜現在。stage 3 以上で `adultAt`=0 なら現在、stage 4 で `finalAt`=0 なら現在で補う |
| `inv.{food}` | int | {} | 既知のエサのみ、0〜999 |
| `day` | string | '' | 12 文字まで |
| `cnt.{タスクid, hamigaki_am, hamigaki_pm}` | int | {} | 0〜9 |
| `lessonDays` | int[] | [6] | 0〜6、重複なし、1〜2 個 |
| `zukan` | string[] | [] | 既知の姿のみ、ずかん順 |
| `shinySeen` | string[] | [] | 既知のおとなのみ |
| `history` | {f,n,g,s}[] | [] | f は既知のおとな、n は 8 文字、g は 1〜9999、s は bool。最新 200 件 |
| `sound` | bool | true | `false` のみ偽 |
| `cfg.sleepAt` / `cfg.wakeAt` | 分 | 1200 / 360 | 1080〜1410 / 240〜540 |
| `cfg.hayaoki` | {from,until,days} | {300,420,[1..5]} | from 240〜600、until は from より後〜660、days は 0〜6 |

### 10.3 バックアップコード
- 形式：`PUNI2:` ＋ Base64（UTF-8 の JSON）。復元時は `PUNI1:`／`PUNI2:` を除去 → 40,000 文字以下かつ Base64 文字のみか確認 → デコード → `sanitize()`。

## 11. 技術仕様

### 11.1 ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | 骨組み、CSP、PWA 用 meta。`<script type="module" src="./js/app.js">` |
| `css/style.css` | 見た目（絵本のページ風、ライト固定）、1 画面のレイアウト、ポーズのアニメーション |
| `js/app.js` | 状態の保持・描画・操作・モーダル・おわかれ（エントリポイント、`APP_VERSION`） |
| `js/data.js` | タスク・エサ・姿・中国語・セリフのデータ |
| `js/rules.js` | DOM に触れない純粋なルール（時間帯・受付・時間経過・分岐・期日・表情・セリフ選び） |
| `js/state.js` | 保存形式（`DEF`・`sanitize`・バックアップコード） |
| `js/art.js` | SVG 描画 |
| `js/sound.js` | 効果音・鳴き声・読み上げ |
| `sw.js` | オフラインキャッシュ |
| `manifest.webmanifest` / `icons/` | ホーム画面追加（standalone、テーマ色 `#F7B5CF`） |

### 11.2 セキュリティ
- CSP：`default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'self'; …; object-src 'none'; base-uri 'none'; form-action 'none'`
- インラインスクリプト・インライン style 属性・インラインイベントハンドラなし。幅は JS から `el.style.width` で設定。
- 利用者入力（なまえ・よびかた・history のなまえ）を `innerHTML` に入れる箇所は `esc()`。吹き出し・ヘッダー・おわかれの文は `textContent`。
- 保存データ・復元コードは `sanitize()` で既知のキーと型のみ取り込む。

### 11.3 Service Worker（`sw.js`）
- キャッシュ名 `punipuni-<VERSION>`。install で `ASSETS` を HTTP キャッシュを通さずに（`cache:'reload'`）事前キャッシュして `skipWaiting`、activate で古い `punipuni-*` を削除して `clients.claim`。
- fetch：同一オリジンの GET のみ、キャッシュ優先（クエリ無視）→ なければネットワーク。
- `ASSETS` に含まれるファイルを変えたら `VERSION` と `APP_VERSION` を上げる。端末側は設定の「アプリを更新する」で新版にできる。

## 12. 既知の仕様上の注意点
- 夜 0:00〜5:59 のはみがきは当日の「あさ」枠を消費する。
- 日付判定・ねんね判定・一生の期日は端末の時計に依存する。
- 長期間放置しても時間経過の計算は直近 40 日ぶんまで。放置後は病気になっていることが多く、おわかれの前にエサ 2 つで治す必要がある。
- あかちゃん・こども の姿は重複する（重複なしはおとなのみ）。
