# ぷにぷに にっき 仕様書（v1）

> 対象：`js/app.js`・`index.html`・`css/style.css`・`sw.js`（Service Worker `VERSION = 'v1.0.0'`）時点の実装。
> 数値はすべて実装の定数から抜き出したもの。挙動を変えたら本書も更新すること。
> 開発者向けの早見表は [`spec-summary.md`](spec-summary.md)。

## 1. 概要

| 項目 | 内容 |
|---|---|
| 目的 | 現実の習慣（中国語・歯みがき・野菜・お風呂）を報告 → エサをもらう → 育てる、で習慣づけを楽しくする |
| 利用者 | 娘（ひらがなのみ読める）。設定画面のみ保護者 |
| 端末 | iPad Safari（ホーム画面に追加して standalone 起動）。PC ブラウザでも動作 |
| 形態 | 静的サイト（HTML/CSS/JS のみ、依存ライブラリなし、ビルドなし） |
| 通信 | 外部通信なし。CSP で `'self'` のみ許可 |
| 保存 | 端末の `localStorage`（キー `punipuni-nikki-v1`） |
| 子ども向け配慮 | キャラは死なない。罰はなく「お世話で回復する」設計 |

### 基本ループ
```
現実でタスクをする → 「できたこと を おしえてね」で報告（「できた？」確認）
  → エサがトレイに入る → エサをタップしてあげる
  → ポイント・パラメータ上昇 → しきい値で進化 → おとな → つぎのたまご（次世代）
```

## 3. タスクとエサ

### 3.1 タスク一覧（1 日あたり）
| id | 表示名 | 上限 | もらえるエサ |
|---|---|---|---|
| `lesson` | ちゅうごくご れっすん | 1 回。**設定した曜日のみ**（初期値：土曜） | にくまん 🥟 |
| `jishu` | ちゅうごくご じしゅう | 1 回 | ことばのみ 🍒 |
| `hamigaki` | はみがき | あさ 1 回（0:00〜14:59）・よる 1 回（15:00〜23:59） | きらきらあめ 🍬 |
| `yasai` | おやさい | 3 回 | やさいすーぷ 🥣 |
| `ofuro` | おふろ | 1 回 | あわあわぷりん 🍮 |

- 報告時は確認モーダル「◯◯ できた？」を出し、「できた！」でエサを 1 つトレイに追加。
- はみがきの確認文言は時間帯で「あさの はみがき」「よるの はみがき」に変わる。
  - 注意：0:00〜6:59 の夜ふかし中のはみがきは **その日の「あさ」枠** として数えられる。
- レッスンを報告すると **ぐんぐんたいむ** 開始（報告時刻から 24 時間）。再報告で延長ではなく「その時点から 24 時間」に上書き。
- タスク表示：
  - レッスン：対象外の曜日は「◯ようび だけ」＋📅、当日未報告は「きょうは れっすんの ひ！ ごはん 3ばい」、報告済は「できたね！」
  - はみがき：あさ／よるのドット
  - その他：上限数ぶんのドット（済は塗りつぶし）
  - 右端：未達ならもらえるエサのアイコン、達成済なら 💮

### 3.2 日付リセット
- 端末ローカル時刻の日付（`YYYY-M-D`）が変わったら当日の回数 `cnt` をクリア。
- 未使用のエサ（`inv`）は持ち越し。上限なし（保存時は各 999 まで）。

### 3.3 エサの効果
| エサ | ポイント | パラメータ | おなか | ごきげん | 備考 |
|---|---|---|---|---|---|
| にくまん 🥟 | 3 | かしこさ +3 | +2 | — | 中国語の単語を話す |
| ことばのみ 🍒 | 1 | かしこさ +1 | +1 | — | 中国語の単語を話す |
| きらきらあめ 🍬 | 1 | きれい +1 | +1 | — | |
| やさいすーぷ 🥣 | 1 | げんき +1 | +1 | — | |
| あわあわぷりん 🍮 | 1 | ほかほか +1 | +1 | +1 | |

- ぐんぐんたいむ中は **ポイントとパラメータのみ 1.5 倍**（小数のまま加算。表示は切り捨て）。おなか・ごきげんは倍にならない。
- おなか・ごきげんの上限は 4。
- たまご期（stage 0）はおなか・ごきげんは変化しないが、**ポイントとパラメータは加算される**（進化分岐に影響する）。
- 病気中にあげたエサは「治療」に使われ、ポイント・パラメータは増えない（おなか・ごきげんは増える）→ §5.3。
- エサをあげると最後のお世話時刻 `lastCare` を更新（病気判定の起点）。

## 4. 成長と進化

### 4.1 段階としきい値（累計ポイント）
| stage | 段階 | 到達条件 |
|---|---|---|
| 0 | たまご | 初期 |
| 1 | あかちゃん | 3pt |
| 2 | こども | 10pt |
| 3 | おとな | 25pt |

- エサをあげた後に判定。1 回で複数段階を越える場合は、進化モーダルを閉じるたびに次の進化が続けて起こる。
- たまご → あかちゃん時に、おなか・ごきげんを 3 に、時間経過の積算をリセット（孵化直後に減らないように）。
- おとな到達後もポイント・パラメータは増え続けるが、進化はしない。

### 4.2 進化先の決まり方（進化する瞬間のパラメータで判定）
| 進化 | 条件 | 進化先 |
|---|---|---|
| たまご → あかちゃん | 常に | ぷにぷに（`puni`） |
| あかちゃん → こども | かしこさ＋きれい ≧ げんき＋ほかほか | ほしぷに（`hoshi`） |
| | それ以外 | はなぷに（`hana`） |
| こども → おとな | 4 パラメータすべて > 0 かつ 最大 / 最小 ≦ 1.6 | **にじぷに**（`niji`、レア） |
| | それ以外：最大のパラメータで決定 | かしこさ→はかせぷに／きれい→きららぷに／げんき→もりもりぷに／ほかほか→ぽかぽかぷに |

- 最大が同値の場合は かしこさ → きれい → げんき → ほかほか の順で先のものが優先。
- こども段階の分岐（ほし／はな）は、おとなの分岐には影響しない（おとなはパラメータのみで判定）。

### 4.3 キャラクター（全 8 種、ずかん順）
| id | 名前 | 特徴（SVG アクセサリ） | ずかんのヒント（未発見時） |
|---|---|---|---|
| `puni` | ぷにぷに | 耳なし・頭に毛、やや小さめ | たまごから うまれるよ |
| `hoshi` | ほしぷに | 頭に星 | かしこさ と きれい を そだてると… |
| `hana` | はなぷに | 頭に花 | げんき と ほかほか を そだてると… |
| `hakase` | はかせぷに | めがね・博士帽 | かしこさ が いちばん だと… |
| `kirara` | きららぷに | 王冠・きらきら | きれい が いちばん だと… |
| `morimori` | もりもりぷに | 頭に葉っぱ | げんき が いちばん だと… |
| `pokapoka` | ぽかぽかぷに | タオル・湯気 | ほかほか が いちばん だと… |
| `niji` | にじぷに | 背景に虹・小さな星 | ぜんぶ なかよく そだてると… |

- すべてオリジナルデザイン（既存キャラの模倣禁止）。
- たまごはポイント 2 以上でヒビが入る。
- 表情：`sleep` ＞ `sick` ＞ `happy`（エサ・なでる直後 2.5 秒）＞ `sad`（おなか 0 または ごきげん 0）＞ `normal` の優先順。

### 4.4 ずかん
- 進化で新しい姿になった時に登録（たまごは対象外）。
- 未発見は灰色シルエット＋「？？？」＋ヒント。見出しに「ずかん（発見数 / 8）」。

### 4.5 つぎのたまご（世代交代）
- おとなの時だけ 🥚 ボタンが出る。確認後、新しいたまごから開始。
- **引き継ぐもの**：世代数（+1）、ずかん、レッスン曜日、所持エサ、当日の日付と回数、ぐんぐんたいむ終了時刻。
- **初期化されるもの**：段階・姿・ポイント・パラメータ・おなか・ごきげん・病気・なでた時刻、**なまえ（「ぷにちゃん」に戻る）**。

## 5. 状態と時間経過

### 5.1 起きている時間
- **ねんねモード：21:00〜6:59** は時間経過による減少・病気の進行が止まる。
- 経過時間は 5 分刻みで「起きている時間」だけを積算（最大で直近 40 日ぶん）。
- 判定タイミング：起動時、30 秒ごと、アプリが前面に戻った時（`visibilitychange`）。
- たまご期は時間経過の影響を一切受けない（減少も病気もなし）。

### 5.2 ゲージ（0〜4、初期値 3）
| ゲージ | 減り方 | 増やし方 |
|---|---|---|
| おなか 🍙 | 起きている時間 3 時間ごとに −1 | エサ（にくまん +2、他 +1） |
| ごきげん 🌸 | 起きている時間 4 時間ごとに −1 | なでる（30 分に 1 回だけ有効 +1）、あわあわぷりん +1 |

- 0 になっても死亡・ペナルティはなし（表情が `sad` になるだけ）。

### 5.3 びょうき
- 発症：最後にエサをあげてから **起きている時間で 12 時間** 経過（孵化時も起点をリセット）。
- 症状：表情 `sick`、バッジ「🤒 びょうき：ごはん あと N こ で なおる」、なでても回復しない。
- 回復：エサを **2 つ** あげる（種類は問わない）。1 つ目「もう ひとつ たべたら なおりそう」、2 つ目で「げんきに なったよ！」＋ 🌈。
- 病気中はエサでポイント・パラメータが増えない（＝成長しない）。ぐんぐんたいむも適用されない。

### 5.4 ねんね表示
- 21:00〜6:59 かつ最後の操作（エサ・なでる・報告）から 2 分以上経過で、寝顔・夜背景・「💤 ねんね ちゅう」を表示。操作すると起きる。

### 5.5 なでる（キャラをタップ）
| 状態 | 反応 |
|---|---|
| たまご | 「ころころ… なかで なにか うごいてる！」 |
| 病気 | 「うーん… ごはん たべたら げんきに なるかも」（ごきげん変化なし） |
| それ以外 | ごきげん +1（前回有効から 30 分超の時のみ）、💗、笑顔。こども以上は 50% で中国語の単語を話す |

## 6. 中国語・読み上げ
- 単語 12 語（例：你好／にーはお／こんにちは）からランダム。吹き出しに「◯◯「ひらがな読み」は ちゅうごくごで「意味」だよ！」＋ 簡体字。
- 話すタイミング：にくまん・ことばのみをあげた時（たまご期・病気中を除く）、こども以上をなでた時の 50%。
- 🔊：Web Speech API で吹き出しの日本語（`ja-JP`）→ 中国語（`zh-CN`）の順に読み上げ（速度 0.9）。非対応端末では何もしない。

## 7. おうちの方の設定（⚙️ 1 秒長押し）
文言は漢字可。

| 項目 | 仕様 |
|---|---|
| なまえ | 最大 8 文字。空欄なら変更しない。「保存する」で反映 |
| 中国語レッスンの曜日 | 日〜土から 1 つ（初期値：土曜） |
| コードを表示・コピー | バックアップコードを表示し、クリップボードへコピー（失敗時は長押しコピーを案内） |
| コードから復元 | 貼り付けたコードを検証して置き換え。失敗時「コードが正しくありません…」 |
| 最初からやり直す | 1 回目のタップでボタンが「本当に消す？もう一度タップ」に変わり、2 回目で全データ初期化（ずかん含む） |

## 8. データ

### 8.1 保存
- `localStorage['punipuni-nikki-v1']` に JSON で保存。操作のたび・30 秒ごとに保存。
- 起動時に `navigator.storage.persist()` を要求（消去されにくくする）。
- 読み込み失敗・不正データ時は初期データで開始。

### 8.2 保存形式（`v:1`）
| キー | 型 | 初期値 | 検証（`sanitize()`） |
|---|---|---|---|
| `v` | 1 | 1 | 1 以外は拒否 |
| `name` | string | `ぷにちゃん` | trim して 8 文字まで。空なら初期値 |
| `gen` | int | 1 | 1〜9999 |
| `stage` | int | 0 | 0〜3 |
| `form` | string | `egg` | `FORMS` のキーのみ。stage 0 なら `egg`、stage>0 で `egg` なら `puni` |
| `pts` | number | 0 | 0〜1e6 |
| `p.{ka,ki,ge,ho}` | number | 0 | 0〜1e6（かしこさ／きれい／げんき／ほかほか） |
| `hunger` / `mood` | int | 3 | 0〜4 |
| `hAcc` / `mAcc` | ms | 0 | 0〜1e10（減少までの積算） |
| `sick` | bool | false | `true` のみ真 |
| `cure` | int | 0 | 0〜2 |
| `lastCare` / `lastTick` | ms | 現在 | 0〜現在 |
| `petAt` | ms | 0 | 0〜現在 |
| `boostUntil` | ms | 0 | 0〜現在+24h |
| `inv.{food}` | int | {} | 既知のエサのみ、0〜999 |
| `day` | string | '' | 12 文字まで |
| `cnt.{lesson,jishu,yasai,ofuro,hamigaki_am,hamigaki_pm}` | int | {} | 0〜9 |
| `lessonDay` | int | 6 | 0〜6（0=日曜） |
| `zukan` | string[] | [] | 既知の姿のみ、ずかん順に並べ直す |

- キーを追加したら `DEF()` と `sanitize()` の両方に追加すること。
- 形式を変える場合は旧データの移行処理を書く（育成データを消さないことが最優先）。

### 8.3 バックアップコード
- 形式：`PUNI1:` ＋ Base64（UTF-8 の JSON）。
- 復元時：`PUNI1:` を除去 → 20,000 文字以下かつ Base64 文字のみか確認 → デコード → `sanitize()`。

## 9. 技術仕様

### 9.1 ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | 骨組み、CSP、PWA 用 meta |
| `css/style.css` | 見た目、ライト／ダークのトークン |
| `js/app.js` | ロジック・SVG 描画（IIFE、`'use strict'`、依存なし） |
| `sw.js` | オフラインキャッシュ |
| `manifest.webmanifest` / `icons/` | ホーム画面追加（standalone、テーマ色 `#FF9CBE`） |

### 9.2 セキュリティ
- CSP：`default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'self'; …; object-src 'none'; base-uri 'none'; form-action 'none'`
- インラインスクリプト・インライン style 属性・インラインイベントハンドラなし。幅は JS から `el.style.width` で設定（`data-w` 属性経由）。
- 利用者入力（なまえ）を `innerHTML` に入れる箇所は `esc()` でエスケープ。ヘッダーは `textContent`。
- 保存データ・復元コードは `sanitize()` で既知のキーと型のみ取り込む（`__proto__` 等の混入対策）。
- `referrer` は `no-referrer`。

### 9.3 Service Worker（`sw.js`）
- キャッシュ名 `punipuni-<VERSION>`。install で `ASSETS` を事前キャッシュ、activate で古い `punipuni-*` を削除。
- fetch：同一オリジンの GET のみ、キャッシュ優先（クエリ無視）→ なければネットワーク。
- `ASSETS` に含まれるファイルを変えたら `VERSION` を上げる。端末側はアプリを 2 回起動し直すと新版になる。

## 10. 既知の仕様上の注意点
- 夜 0:00〜6:59 のはみがきは当日の「あさ」枠を消費する。
- つぎのたまごで、なまえが初期値に戻る。
- 日付判定・ねんね判定は端末の時計に依存（時計を変えると回数がリセットされうる）。
- 長期間放置しても時間経過の計算は直近 40 日ぶんまで（おなか・ごきげんは 0 止まり、病気のみ）。
