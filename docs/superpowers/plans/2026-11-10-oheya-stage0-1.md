# おへや 段階0＋段階1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 段階0で Canvas 2D のアイソメ部屋が iPad で耐えるかを確かめる試作を作って止まり、オーナーの判断のあと段階1でホーム画面の背景を「見るだけのおへや」に置き換え、主役のぷにが自律行動するようにする。

**Architecture:** 純ロジック `js/room-ai.js`（行動・BFS・動き）と `js/room-art.js`（SVG と配置）は DOM に触れない ES モジュール。`js/room.js` が Canvas・rAF・投影・キャッシュ・`#pet` の位置合わせを持ち、`js/app.js` は `render()` から状態を渡すだけ。Canvas が使えなければ今の表示に戻す。

**Tech Stack:** 素の ES モジュール（ビルドなし・依存なし）、Canvas 2D、SVG 文字列 → `data:` 画像、JSDoc の型、Node v24 の `node:test`（`package.json` なし）、Playwright MCP（ヘッドレス Chromium）。

**Spec:** `docs/superpowers/specs/2026-11-10-oheya-stage0-1-design.md`（構想は `docs/oheya/CONCEPT.md`）

## Global Constraints

- 作業はすべて `feature/oheya`。`main` に入れない・`main` へプッシュしない（関門 G1 まで）。
- 静的サイトのみ。`package.json`・ビルド・npm 依存・ライブラリを足さない。
- CSP は変えない（`'self'` 以外を足さない。`img-src 'self' data:` は既存）。外部通信をしない。
- インライン `<script>`・`style=""`・`onclick=""` を書かない。大きさ・位置は `el.style.x`。
- 利用者の入力値を `innerHTML`・SVG に入れない（`petSVG` には入らない）。表示は `textContent`。
- 保存形式（`v:2`）・`DEF()`・`sanitize()` を変えない。
- UI 文言はひらがなのみ。キャラは死なない・罰なし。オリジナルデザインのみ。
- 移植したコードは冒頭に出所（リポジトリ・パス・コミット）と変更点を書く：oekaki b1611f5、odori 9cef958、orbit f2a74b1。
- テスト：`node --test tests/*.test.js`。構文チェック：`for f in js/*.js dev/*.js; do node --check "$f"; done`。
- ブラウザ確認は `http://localhost:8000` のみ（`python3 -m http.server 8000` をバックグラウンドで起動）。
- コミット前に毎回：`security-reviewer` サブエージェント → `/security-review` → 構文チェック・テスト・Playwright。
- 段階0は `VERSION` を上げない。段階1で `sw.js` の `VERSION` と `js/app.js` の `APP_VERSION` を `v2.5.0` にし、`ASSETS` に `./js/room.js`・`./js/room-ai.js`・`./js/room-art.js` を足す。
- 実機（iPad）の滑らかさ・発熱は測れたふりをしない。コンテナの数値は「ヘッドレス Chromium の参考値」と書く。

## Review Focus

1. **画面の向きを途中で変える**（iPad を回す）→ Canvas が収まり直し、`#pet` が絵に重なったまま `.screen` の外にはみ出さない。→ Task 7（`petBox` のテスト）と Task 9（Playwright で 820×1180→1180×820）。
2. **歩いている途中で状態が変わる**（夜になる・病気になる・指で押さえる・新しい たまご）→ 瞬間移動せず、通れないマスや部屋の外で止まらない。たまごになったら `home` に置き直す。→ Task 4 のテスト。
3. **裏に長く置いてから戻る**（数時間）→ 早送りしない（`dt` 0.1 秒で切る）。暗さは目標へ一気に合わせる（6 秒かけて暗くならない）。→ Task 4・Task 7 のテスト。
4. **進化・復元・世代交代で形が変わる**→ 新しい絵が読めるまで前の絵を出し、キャッシュは 40 件を超えない。→ Task 7（`SpriteCache` のテスト）。
5. **ぷにがほんだなの裏・部屋のはしにいるときのタッチ**→ 当たり判定は最小 96px を保ちつつ `.screen` の中に収める。→ Task 7（`petBox` のテスト）。
