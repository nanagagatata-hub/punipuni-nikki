## 方針

### 1. 保存データ（消さないことが最優先）
- 保存キー `punipuni-nikki-v2`・形式 `v:2` はそのまま。項目を足すだけにする。古い v2 データでは新しい項目が無いので、`sanitize()` が初期値で補う（`js/state.js`）。
- 新しい項目（`DEF()` と `sanitize()` の両方に追加）。時刻はすべて 0 時からの分（整数）で持つ。
  - `cfg.sleepAt`: 1200。範囲 1080〜1410（18:00〜23:30）
  - `cfg.wakeAt`: 360。範囲 240〜540（4:00〜9:00）
  - `cfg.hayaoki`: `{from:300, until:420, days:[1,2,3,4,5]}`。from は 240〜600、until > from、days は 0〜6 で重複なし
  - `cfg.hayane`: `{from:1080, until:[1200,1200,1200,1200,1200,1260,1260]}`。添字は曜日（0=日）。どれも from より後で 1439 以下
  - `cfg.tempWake`: false。ボタンを出す許可
  - `tempUntil`: 0。臨時で起きている終わりの時刻（ms）。0〜現在+5 分に丸める
  - `tempNight`: ''。臨時で起こした夜の識別（`dayKey`、12 文字まで）
- 不正な値は、その項目だけを初期値に戻す（ほかの項目は捨てない）。
- `cnt`・`inv` のキーは `TASKS`・`FOODS` から作っているので、どらいやー も自動で検証対象になる（`js/state.js` の `CNT_KEYS`）。
- 確認すること：
  - v2.0.0 の `DEF()` の形で作った保存データ（育成途中・ずかん・history あり、cfg なし）を読み込んでも、すべての値が変わらないこと
  - v2.0.0 で書き出した `PUNI2:` のコードを復元できること
  - v1 キーからの移行も今までどおり動くこと

### 2. 時間のルール（`js/rules.js`）：設定を受け取る形に変える
- 時間帯：`band(d, cfg)` の区切りは次のとおり。
  - よる＝`sleepAt`〜`wakeAt`
  - あさ＝`wakeAt`〜10:00
  - ひる＝10:00〜16:00
  - ゆうがた＝16:00〜`sleepAt`
- `isNight(d, cfg)` を追加する。`awakeMs(from, to, cfg)` も cfg を受け取るように変え、おなか・ごきげんが減らない時間を設定のねんね時間に合わせる。
- `asleep(S, now)` を追加する。夜であって、かつ臨時で起きていない（`now < S.tempUntil` ではない）ときに真。
  - エサ不可・寝顔・タッチの「むにゃむにゃ」・ひとりごとの停止は、`asleep` で判定する。
  - 時間経過・さいごのすがた への変化・おわかれは、`isNight` で判定する（臨時で起きている間も夜は夜として扱う）。
- `at6(ts, n)` は `atWake(ts, n, cfg)` に変え、さいごのすがた・おわかれの「朝」を `wakeAt` にする（`finalDue`・`farewellReady`）。
- `taskState` / `taskNote`：
  - はやね・はやおき は、`TASKS` の固定値ではなく `S.cfg` から受付時間と曜日を読む。分単位で比べる。
  - 説明文も設定から作る。例：「18じ から」「きょうは おしまい」「げつ〜きん あさ 5じ〜7じ」。半端な分は「6じ30ぷん」のように出す。
- `pickLine` は `band(d, S.cfg)` を使う。
- 呼び出し側：`js/app.js` の `isNight(new Date())` を使っている 7 か所を、目的ごとに `asleep` か `isNight(…, S.cfg)` に置き換える。

### 3. ちょっとだけ おきて（`js/app.js`）
- 次の 3 つがそろったときに、バッジの位置に「⏰ ちょっとだけ おきて」ボタンを出す。
  - `S.cfg.tempWake` が真
  - `asleep` が真
  - `S.tempNight` が今夜の識別と違う
- 今夜の識別は `dayKey`（`wakeAt` より前なら前日）。
- 押すと、`tempUntil = now + 5 分`、`tempNight = 今夜` にする。合わせて、起きた反応（鳴き声・「ふぁ〜 おきたよ」）と、バッジ「⏰ あと N ぷん おきてるよ」を出す。
- 5 分たったら寝顔に戻る。終わりの時刻に合わせて `setTimeout` で `render()` を呼ぶ。30 秒ごとの描画でも追いつく。
- 起きている間は、エサ・タッチがふだんどおり使える。

### 4. どらいやー（`js/data.js`）
- `TASKS` に `{id:'dryer', label:'どらいやー', short:'どらいやー', icon:'🌬️', food:'candy', limit:1}` を足す。
- `FOODS` に `candy:{name:'ふわふわきゃんでぃ', icon:'🍭', pt:1, param:'ki', amt:1}` を足す。
- セリフ・確認モーダルは既存の仕組みのまま使う。

### 5. 設定画面（`js/app.js` の `openSettings`）
- 「生活リズム」の見出しを足し、次の欄を置く。
  - ぷにちゃんが寝る時刻・起きる時刻
  - はやおき の開始・終了時刻と曜日（チェック 7 つ）
  - はやね の開始時刻と、日〜土それぞれの締め切り時刻
  - 「ちょっとだけ おきて」ボタンを出す（オン／オフ）
- 時刻は `<input type="time" step="300">`、曜日は `<input type="checkbox">`。値の検証は `sanitize` と同じ関数で行う。範囲外のときは保存せず、トーストで知らせる。
- 文言は漢字可（約束 7）。

### 6. 絵本のページ風の見た目（`css/style.css`・`index.html`・`js/art.js`）
- ダークモードの指定（`prefers-color-scheme: dark` と `[data-theme="dark"]` のブロック）を削除する。`<meta name="color-scheme" content="light">` を足す。
- 背景：生成り色の紙（例 `#FFF8EE`）に、ごく薄い水玉と紙の質感。ラジアルグラデーションで描き、画像は使わない。
- ゲーム機の外枠 `.shell` をやめ、`.frame` にする。居住枠（`.screen`）と同じ角丸の、絵本の額にする。
  - 手描き風の二重線と、内側の点線ステッチ
  - 外枠と中の角丸をそろえる（外の角丸＝中の角丸＋外枠の太さ）
  - 吹き出し・エサのトレイ・できたこと・つよさ は、紙のカード（点線のふち・やわらかい影）にする
- 景色：`art.js` に `sceneSVG(band)` を足す。`#screen` の一番うしろに置き、`pointer-events:none`、`preserveAspectRatio="xMidYMax slice"` にする。4 つの時間帯で色・光・景色を大きく変える。
  - あさ：桃色〜レモン色の空、のぼる太陽、うすみどりの丘、ことり
  - ひる：はっきりした水色の空、白い雲、太陽、みどりの丘と花
  - ゆうがた：オレンジ〜ラベンダーの空、大きな夕日、こい色の丘、いちばんぼし
  - よる：絵本の夜の藍色（紺ではなく紫みのある色）、三日月、星、くらい丘、あかりのついた小さな家
  - 文字の色は時間帯ごとに読める色にする（コントラスト 4.5:1 以上）
  - 今の CSS の飾り（☀️☁️🌷 など）は景色に置きかえて消す
- できたこと のタイル：
  - 縦画面は `grid-template-columns: repeat(5,1fr)`
  - 横画面は `repeat(3,1fr)` × 3 行
  - 1 画面に収める `@media` ブロック（CSS の末尾にある）を調整する
- manifest と `theme-color` も紙の色に合わせる。

## 確認方法
- 構文：`for f in js/*.js; do node --check "$f"; done`
- node の確認スクリプト：
  - **データ：** v2.0.0 の保存データ（cfg なし）をそのまま読めること（全項目一致）。不正な cfg（範囲外の時刻・until ≦ from・曜日 9・`__proto__`）が項目ごとに初期値に戻ること。`tempUntil` の上限。
  - **時間：** 初期設定のときの band・受付時間が v2.0.0 と同じ結果になること（既存の task3 / task5 がそのまま合格）。
  - **設定を変えたとき：** sleepAt=21:00 なら 20:30 は夜ではなく、エサがあげられること。wakeAt=7:00 なら 6:30 は夜、おわかれは 7:00 からになること。はやね の金曜だけ 22:00 締め切り。はやおき の土曜を追加。
- Playwright（`http://localhost:8000`、偽の時計を使う）：
  - 既存の smoke・t3-night・t5-life・t10-settings・final-ui がすべて合格すること（キーと時刻の前提が変わる所はスクリプトを直す）。
  - 設定画面で時刻と曜日を変えて保存し、タスクの受付と説明文が変わること。
  - 「ちょっとだけ おきて」：許可オフでは出ない。オンで夜に出る → 押すとエサがあげられる → 5 分後に寝る → 同じ夜にはもう出ない → 次の夜はまた出る。
  - 端末をダークモードにしても、明るい絵本の色のままであること。
  - 1 画面：iPad mini 縦 744×1133／744×1109、横 1133×744／1133×720 で、スクロールなし・9 タイルが見える・タイル 64px 以上・キャラ 200px 以上（既存の `fit.js` を 9 タイル用に直す）。
  - コンソールエラー（CSP 違反を含む）が無いこと。
  - 4 つの時間帯と さいごのすがた・ずかん の画像を `screenshots/` に書き出し、ユーザーに見てもらう。
- 公開前：今の公開版の保存データ（v2.0.0 の形）を `localStorage` に入れて新しい版を開き、育成状態が変わらないことを最終確認する。
