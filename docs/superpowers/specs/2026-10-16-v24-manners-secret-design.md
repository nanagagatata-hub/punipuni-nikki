# ぷにぷに にっき v2.4 アップデート計画（ごはんマナー・おどり・おわかれの歌・ずかん・姿の追加・スーパーシークレット）

## Context
v2.3.0 を公開済み（main = 6d38116）。娘さんがもっと楽しく続けられるよう、次の要望が出た。
- できたこと に「ごはんマナー」（2 点）を足す。もらったエサをあげると、ぷにちゃんが約 5 秒おどる（スペシャル感）
- さいごのすがた が旅立つときに、あいさつだけでなく歌ってくれる
- ずかんで見つけたぷにちゃんにタッチすると反応する
- あかちゃん・こども の種類を、おとな（11 種）と同じ数にする
- ずかんを全部うめた先に「スーパーシークレット」のおとなを用意する。ずかんにも載せて期待をあおり、見た目と声も特別にする

条件：育成中のぷにちゃんを消さない（保存キー `punipuni-nikki-v2`・形式 `v:2` は据え置き、足すだけ）。プッシュはユーザーの許可のあと。

## 方針

### 1. データ（`js/data.js`・`js/state.js`）
- **タスク：** `TASKS` に `{id:'manners', label:'ごはんの まなー', short:'まなー', icon:'🍽️', food:'parfait', limit:3}` を足す。回数の上限は `S.cfg.manners` から読む（`taskState` で `limit` を差し替える）。
- **エサ：** `FOODS` に `parfait:{name:'にこにこぱふぇ', icon:'🍨', pt:2, param:'ki', amt:2, dance:true}` を足す。
- **設定：** `CFG_DEF()` に `manners:3` を足し、`cleanCfg` で整数 1〜5 だけを受け付ける（範囲外は 3）。
  - `cnt`・`inv`・`undo` のキーは `TASKS`・`FOODS` から自動で作るので、manners と parfait も自動で検証対象になる。
- **姿：** `FORMS` に、あかちゃん 7 種・こども 7 種・シークレット 1 種を足す（名前・stage・color・dark・hint・ひとこと `say:[…]`・声の高さ `voice`）。既存の 19 種にも `say`・`voice` を足す。
  - あかちゃん（新しい 7 種）
    - 2 つ型：ka+ki `kirapuni`・ka+ge `pyonpuni`・ka+ho `nukupuni`・ki+ge `kazepuni`・ki+ho `awapuni`・ge+ho `potapuni`
    - バランス型：`maruppuni`
  - こども（新しい 7 種）
    - 2 つ型：ka+ki `hanabi`・ka+ge `tanken`・ka+ho `hon`・ki+ge `mizutama`・ki+ho `ribon`・ge+ho `donguri`
    - バランス型：`sorairo`
  - シークレット：`yumeniji`（stage 3、`secret:true`）
  - 名前・ひらがな表記・絵の意匠は実装時に決め、画像で見てもらう。既存キャラの模倣はしない（約束 9）。
- **ずかんの順：** `ZORDER` は あかちゃん 11 → こども 11 → おとな 11 → シークレット。
  - `ADULT_IDS` にはシークレットも含める。`history`・`shinySeen` の検証で必要なため。
  - ふつうのおとなの候補は `NORMAL_ADULTS`（シークレットを除いた 11 種）として別に持つ。
- **旧データ：** 既存の ID はそのまま有効。`zukan` は `ZORDER` で絞るので、新しい子は「まだ見つけていない」として扱われる。

### 2. 分岐（`js/rules.js` の `chooseForm`）
- 3 つの段階で共通の決め方 `pickByParams(p, table)` を使う（今のおとなの決め方を一般化する）。
  - 第 1 候補：4 つすべて > 0 かつ 最大/最小 ≦ 1.6 ならバランス型。そうでなく、2 位 ≧ 1 位 × 0.75 なら 2 つ型。それ以外は 1 つ型。
  - 残りの候補は、相性スコアの高い順に並べる。
- **あかちゃん：** 第 1 候補（重複してよい）。
- **こども：** ずかん に無い子を、第 1 候補 → 相性スコアの順で選ぶ。11 種すべて見つけていたら第 1 候補（色違いなし）。
- **おとな：**
  1. `yumeniji` が ずかん に無く、かつ あかちゃん・こども・おとな の 33 種がすべて ずかん にあれば、`yumeniji` にする。
  2. そうでなければ今と同じ。`NORMAL_ADULTS` から ずかん に無い子を選び、11 種そろっていたら色違いにする。
- **既存のテスト：** task4 を新しい表に合わせて書き直す。今までの 1 つ型の結果（ぷにぷに・ほしぷに など）は変わらない。

### 3. ごはんマナー と おどり（`js/app.js`・`css/style.css`・`js/sound.js`）
- **タスク：** `taskState` で manners の上限を `S.cfg.manners` にする。タイルの丸の数も設定に合わせる。
- **設定画面：** 「ごはんマナーの回数（1日）」の選択欄（1〜5）を足す。
- **おどり：** `feed()` で `FOODS[fid].dance` のとき、ふだんの食事の反応のあとに `dance()` を呼ぶ。
  - `#pet` に `data-pose="dance"` を 5 秒付ける。CSS の keyframes で、左右ステップ → くるっ → ジャンプ を 5 秒に収める。
  - `sound.js` に `sfx('dance')`（約 5 秒の明るいメロディ）を足す。
  - ♪♫ と紙ふぶきを `fxBurst` で 1 秒ごとに出す。
  - セリフ `LINES.dance` を出す。
  - おどりの間はタッチの反応を出さない。おどりの途中でもエサやり・報告はできる。
  - 「視差効果を減らす」では動かさず、曲とセリフだけにする。

### 4. おわかれの歌（`js/app.js`・`js/sound.js`・`js/data.js`）
- `startFarewell` の 3 ページ目（たびにでる）と「わたすね」の間に、歌のページを入れる。
- **歌のデータ：** `data.js` の `SONG` に `[{t:'ひらがなの歌詞', notes:[[音の高さ,長さ],…]}, …]`（4〜6 行・約 20 秒）を持つ。歌詞の `{you}` は よびかた に置き換える（`textContent`）。
- **再生：** `sound.js` の `sing(lines, onLine)` が、1 行ずつ鳴き声の音色でメロディを鳴らし、行が変わるたびに `onLine(i)` を呼ぶ。音がオフのときは、同じ間隔で行だけ進める。
- **画面：** 今歌っている行を大きく光らせ、ぷにちゃんは `sway` のポーズ。歌い終わると「つぎへ」が押せる。「とばす」はおうちの方のために小さく置く。

### 5. ずかんのタッチ（`js/app.js` の `openZukan`・`css/style.css`）
- 見つけたセル（`.zc[data-form]`）を押すと、次のことが起きる。
  - そのセルの絵を笑顔（`petSVG(f,'happy')`）に差し替え、`zjump` のアニメーションで跳ねる
  - `sfx('cry', FORMS[f].voice)` で、その子の高さの声で鳴く
  - そのセルの下に、その子のひとこと（`FORMS[f].say` からランダム）を `textContent` で 2 秒出す
- まだ見つけていないセルは「まだ あえて ないよ」と少しゆれる。
- `sound.js` の `cry` が、高さの倍率を受け取れるようにする。シークレットは `sfx('chord')`（和音）。

### 6. スーパーシークレット「ゆめにじぷに」（`js/art.js`・`css/style.css`）
- **見た目：** `petSVG` に `opt.secret`（`FORMS[f].secret` で自動）を足す。
  - 体を SVG のグラデーションにし、CSS で `filter: hue-rotate()` をゆっくりかけて色を回す（style 属性は使わない）
  - 星の王冠ときらきら、まわりにふわふわした光の粒
- **声：** なでなで・ずかんでは `sfx('chord')`（3 つの音を重ねた鳴き声）。
- **ずかん：**
  - 一番最後に「スーパーシークレット」の大きめの枠を置く。見つける前は、にじ色のシルエット＋「？？？」＋「ぜんぶの ぷにちゃん に あうと…？」＋「あと ◯しゅるい」。
  - 見つけたら、きらきらの枠になる。
- **進化のとき：** モーダルの文を「すーぱー しーくれっと！」にし、紙ふぶきを増やす。

### 7. 配置・版・文書
- **タイル：** できたこと が 10 個になる。縦は 5×2 のまま。横は 3×3 → 5×2 に変え、iPad mini の 1 画面を維持する（`fit.js` で確認）。
- **ずかん：** 34 枠になるので、モーダルの中でスクロールする（今と同じ）。
- `sw.js` の `VERSION` と `APP_VERSION` を `v2.4.0` にする。`docs/spec.md`・`spec-summary.md` を更新する。

## 進め方
1. main からブランチ `feature/v24-manners-secret` を作る。
2. 段階ごとに、確認スクリプト（`.superpowers/sdd/ehon/checks/` の node と Playwright）を先に書いて失敗を確かめ、実装して合格させてからコミットする。
   - (1) データと設定
   - (2) 分岐
   - (3) ごはんマナーとおどり
   - (4) おわかれの歌
   - (5) ずかんのタッチ
   - (6) シークレット
   - (7) 配置
3. 新しい 15 種の絵と、おどり・歌・ずかんの画面を `screenshots/` に書き出し、見てもらってから仕上げる。
4. CLAUDE.md のワークフローに従う：`security-reviewer` → `/security-review` → 動作確認 → VERSION を上げる → **許可を得てから** main に反映してプッシュ。

## 確認方法
- 構文：`for f in js/*.js; do node --check "$f"; done`
- **node の確認スクリプト：**
  - **データ：** v2.3.0 の保存データ（manners なし）を読んでも全項目が変わらないこと。`cfg.manners` は 1〜5 だけ受け付け、それ以外は 3。
  - **分岐：**
    - あかちゃん・こども・おとな それぞれで、1 つ型・2 つ型・バランス型が出ること
    - こどもは ずかん にある子を飛ばすこと、11 種そろったら第 1 候補になること
    - 33 種そろったら次のおとなが `yumeniji` になること、32 種では出ないこと
    - シークレットを見つけたあとは色違いになること
  - **ごはんマナー：** 上限を設定（例 5）に合わせること。parfait は きれい +2・2pt。
- **Playwright（`http://localhost:8000`・偽の時計）：**
  - ごはんマナーを 3 回報告すると 4 回目は押せない。設定を 5 にすると押せる。
  - にこにこぱふぇ をあげると `data-pose="dance"` が約 5 秒付いて、そのあと戻る。「視差効果を減らす」では動かない。
  - おわかれ：歌のページで行が順に光り、歌い終わると「つぎへ」が押せる。音オフでも行が進む。たまごを受け取るところまで進む。
  - ずかん：見つけた子を押すと、跳ねる・ひとことが出る。まだの子は「まだ あえて ないよ」。シークレットの枠に「あと ◯しゅるい」が出る。
  - シークレット：33 種をうめたデータで進化させると「ゆめにじぷに」になり、体の色が変わるアニメーションが付く。
  - 既存のスクリプト（smoke・t-rhythm・t-undo・t-polish・final-ui・fit）がすべて合格し、コンソールエラー（CSP を含む）が無いこと。
- **公開前：** 今の公開版（v2.3.0）の形の保存データで開いて、育成状態が変わらないことを確認する。
