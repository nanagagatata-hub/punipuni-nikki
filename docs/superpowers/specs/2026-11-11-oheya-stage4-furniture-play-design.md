## 2. 使い方の表 `USES`（`js/room-data.js`）
家具 ID ごとに 1 行。`ITEMS` と同じく `table()` で凍結する。

```
/** @typedef {{
 *   spot:'on'|'front'|'side'|'in',   // どこで使う（上に乗る／正面のマス／となりのマス／入口で下半分を隠す）
 *   seat:number,                     // 'on' のときの高さ（部屋の SVG の px。床＝0）
 *   act:'sit'|'sleep'|'read'|'study'|'eat'|'play'|'hug'|'water'|'lamp'|'peek'|'kick'|'slide',
 *   face:string,                     // petSVG の今ある顔だけ（normal・happy・sleep・sparkle・hug・giggle など）
 *   fx:''|'z'|'book'|'pencil'|'snack'|'note'|'heart'|'drop'|'star',  // 頭の上の小さな絵
 *   dur:[number,number],             // 使う秒数（最小・最大）
 *   say:string,                      // 使いはじめのひとこと（ひらがな）
 *   w:number                         // 自分で使うときの重み（0 なら自分では使わない）
 * }} UseDef */
```

## 3. 家具を使う動き（`js/room-ai.js`・`js/room-use.js`）

### 3.1 立ち位置（`js/room-use.js`、DOM に触れない新しいモジュール）
- `useSpot(room, index)` → `{stand:{x,y}, at:{x,y}, lift:number, face:number}|null`
  - `stand`：歩いて行くマス（通れるマス）。`at`：使っている間のぷにの位置（マス座標の実数）。`lift`：持ち上げる高さ（px）。`face`：向き（度）。
  - `on`：
    - 上を歩ける家具（ラグ・くっしょん は `walk:true`）は、足あとの中のいちばん手前の通れるマスへ歩き、そのまま上で使う。
    - 歩けない家具（そふぁ・いす・べっど）は、足あとのまわりの通れるマスへ歩き、`at`＝足あとの中心、`lift`＝`seat` で「上に乗る」。
  - `front`：家具の正面のマス。正面は絵ごとに決め（§3.2）、向き `r` が奇数なら gx と gy を入れ替えた側にする（絵が左右反転のため）。
  - `side`：足あとの 4 方向のとなりで、いちばん近い通れるマス。顔は家具のほう。
  - `in`（てんと）：入口のマス（正面）に立ち、`at` を入口へ 0.4 マス入れる。
  - 正面・となりがふさがっていれば、足あとのまわりの通れるマスのうち、ぷにから歩いていちばん近いマスにする。どこも無ければ `null`。
- どの家具・どの向き `r`・どの部屋の大きさでも、`stand` は部屋の中の通れるマスになることをテストで確かめる。

### 3.2 正面（絵に合わせる。`r=0` のときの向き）
- 正面のある家具（shelf・desk・table・toybox・plant・lamp・tent・ball）は、`r=0` で +gy 側（画面の左下）を正面とする。
- 実装時に各絵を見て +gx 側が正面のものがあれば `USES` に `front:'gx'` を持たせて合わせる（表で決める。コードに家具 ID を書かない）。

### 3.3 頭（`Brain`）に足すもの
- `Act` に `use` を足す。`Brain` に `use:{index:number, id:string, t:number, dur:number}|null` と `goal:{x,y}|null` を足す。
- `goUse(b, grid, spot, index, id, dur)`：`spot.stand` まで歩き、着いたら `use` を始める。歩いている途中に呼ばれたら行き先を変える。
- `goTo(b, grid, cell)`：床のマスへ歩く（呼ぶ）。着いたら正面を向いて 1.5 秒 idle。
- 自分で使う：`pickAct` の重みに `use:15` を足す（`USES[id].w` を持つ家具が部屋に 1 つ以上あるときだけ）。家具は `w` の重みで選ぶ。`reduced` のときも使う（動きは小さくする）。
- 使い終わったら：`on`・`in` の家具は `stand` へ戻ってから idle。それ以外はその場で idle。
- 起きているとき（`mode==='awake'`）だけ使う。`sleep`・`sick`・`hungry`・`egg`・`dance` に変わったら `use` をやめて今までどおりの動きへ。
- `relocateBrain`（部屋が変わった）で `use` と `goal` を捨てる。家具の番号がずれても、使っている家具を描き間違えないため。

### 3.4 夜は べっど で寝る
- `homeWithBed(room)`（`js/room-use.js`）を足し、`room.js` は `homeFor` の代わりにこれを使う：べっど があれば、べっど の `useSpot` の `stand` をおうち（寝る場所）にし、寝ている間は `at`・`lift` で べっど の上に描く。無ければ今までどおり（ラグ → 部屋の中央）。
- 寝る場所の決め方の変更は、べっど が無い部屋の見た目を変えない。

### 3.5 専用の動き（B）
`js/room-use.js` に「経過秒 → 位置・高さ」の純関数として置く。
- `slideMotion(p, t)`（4 秒）：はしごのある側のマスから台の上へ登る（0–1.5 秒、`lift` 0→62）→ 台の上で ばんざい（0.5 秒）→ すべる面にそって手前のはしまで降りる（1.5 秒、`lift` 62→6）→ 着地して ぴょん（0.5 秒）。`r` が奇数なら gx と gy を入れ替える。終わりは すべる面の先のマス（通れなければ はしご側に戻る）。
- `ballMotion(t)`（2.5 秒）：ぷにが けった向きへ、ぼーる の絵を 0.6 マス ころがして（回転つき）戻す。ぼーる の置き場所（保存データ）は変えない。描くときのずれだけ。
- どちらも `t=0` と終わりで、家具の絵のずれが 0 に戻ることをテストで確かめる。

## 4. タップ（おへやの通常時。もようがえ中は今までどおり）

### 4.1 しくみ
- `room.js` の `tapCell` は、もようがえ中は今までどおり `cellCb` へ。通常時は `onTap(cell, hit)` に登録された関数へ渡す（`room-ui.js` が登録）。
- `#roomPet`（なでる）の上のタップは、今までどおり なでる に使う（Canvas に届かない）。

### 4.2 きまり（`room-ui.js`）
1. 家具をタップ（`hit>=0`）：家具をゆらす（§4.3）。`USES` にあれば `room.js` の `useItem(index)` で ぷにを向かわせる。らんぷ なら点灯を切り替える（§5）。
2. 床をタップ：★ を出す（§4.3）。`callTo(x,y)` で ぷにを呼ぶ。
3. 行けないとき（`mode` が `awake` 以外）：手ごたえは出したうえで、ひとことだけ言う。
   - `sleep`：「いまは ねむいの…」、`sick`：「ちょっと しんどいの…」、`hungry`：「おなか すいて うごけないよ」、`egg`：何も言わない、`dance`：何も言わない（踊り終わるまで）
4. 届かない（`useSpot` が `null`、または経路が無い）：「とどかないよ」。
5. 歩いている途中の新しいタップは、行き先を新しい方に変える。

### 4.3 手ごたえ（`room.js`）
- **家具のぶるんっ**：`wiggle(index)`。0.4 秒、足もとを軸に `scaleX=1+0.08·s, scaleY=1−0.08·s`（`s=sin(π·t/0.4)·(1−t/0.4)`）。植物の「おみず」中のゆれも同じしくみを使う。
- **床の ★**：押した点から 5 こ。0.6 秒で外へ 18px ひろがりながら小さく・薄くなって消える。色は今の黄色 `#FFD84D`。点滅なし。
- 「動きを減らす」のときは、ぶるんっ は 0.04 に弱め、★ はひろがらずに その場で薄くなるだけ。
- 同時に出る ★ の組は 4 つまで（古いものから消す）。

## 5. らんぷのあかり

### 5.1 点灯の状態
- `room.js` の中で `lampOff:Set<number>`（置いた順番。入っているものが消えている）を持つ。最初は空（全部ついている）。
- `setRoom` で部屋が入れ替わったら空に戻す（家具の番号がずれるため）。保存しない（開き直すと全部つく）。
- 切り替えは、ぷにが らんぷ の前に着いて `lamp` を始めた瞬間（タップの瞬間ではない）。ぷにが行けないときは切り替えない。
- ぷにが自分から らんぷ を使うことはない（`w:0`）。

### 5.2 見え方
- 絵：`itemSVG('lamp')`（ついている）に加えて、消えている絵 `lampOffSVG()`（かさの色を少し暗く・電球なし。足あと・基準点は lamp と同じ）を `room-art-a.js` から別に export し、`room-art.js` から出す。`ART_A`・`ITEMS` には入れない（おみせ・保存・絵の検査表に出ない）。描くときに消えているらんぷだけ差し替える。
- 夕方・夜（`r.dark>0`）：暗さを重ねたあと、ついている らんぷ のかさの位置を中心に、半径 2.5 マス（部屋の SVG で 80px）の放射グラデーションで
  1. 暗さを抜く（`destination-out`、中心 85% → 外 0%）
  2. あたたかい色 `#FFD9A0` を少し足す（`lighter`、中心 0.18 → 外 0）
  をそれぞれ `r.dark/0.42` の強さで行う。
- 昼：かさのまわりに小さな光（半径 20px、0.15）だけ。
- 点灯・消灯は 1 秒かけて強さを変える（らんぷごとに `0..1` を `approach`）。点滅しない。
- 光らせるのは、ぷにに近い順に 6 こまで。
- 夜のもようがえ（家具を別の板で暗くする処理）でも同じ順で光を足す。

## 6. 描画の追加（`room.js`）
- **ぷにの位置**：`use` 中は `at` と `lift` を使って描く。並べ順は `at` で決め、`on`・`in` のときは使っている家具の直後に描く（家具の上に乗って見えるように）。
- **てんと（in）**：使っている間、ぷにの絵を「てんと の入口の床の線」より上だけ見えるよう `clip` する（体の下 45% を隠す）。顔だけのぞく。
- **頭の上の絵**：`js/room-fx.js` の SVG（Z・本・えんぴつ・おやつ・おんぷ・ハート・しずく・ほし）を `data:` 画像にして 1 回だけ作る。ぷにの頭の右上に、ゆっくり上下（1.5 秒周期、2px）させる。しずく は植物の上から 3 つ落ちる。Z は 3 つが順に浮かぶ。
- **#roomPet**：`use` 中も ぷにの絵に重ねる（なでると `use` をやめて今までどおり止まる）。
- 毎フレームの重さ：頭の上の絵は 1 つ、★ は最大 20 こ、光は最大 6 こ。

## 8. まちがい対策
- 使っている途中で家具が無くなった（もようがえ・復元・世代交代）→ `relocateBrain` で `use` を捨てて idle。
- `useSpot` が `null`・経路なし → 「とどかないよ」。ぷには動かない。
- `hit` の番号は `room.items` の範囲を確かめてから使う。`USES` は `has()` で引く（`__proto__` などを引かない）。
- 1 コマの描画失敗で止めない（今の `try` のまま）。fx の絵が読めなくても部屋は止めない（描かないだけ。`r.fail()` を呼ばない）。
- 文字は `textContent` だけ（ひとことは `host.say`）。`innerHTML` を使わない。

## 9. テスト・確認
### 9.1 `node --test tests/*.test.js`（package.json なし）
- `room-data`：`USES` の全行が `ITEMS` にある ID、`spot`・`act`・`fx` が決まった値、`dur` が正、`say` がひらがな・記号だけ。
- `room-use`：全家具 × 全 `r` × n=6/8/10 で `useSpot` の `stand` が部屋の中の通れるマス。正面がふさがれたら別のマス。囲まれたら `null`。`slideMotion`・`ballMotion` の始まりと終わり。
- `room-ai`：`goUse` → 歩く → `use` → 終わって idle。途中で `goUse` を呼び直すと行き先が変わる。`mode` が `sleep` になると `use` をやめる。`relocateBrain` で `use` が消える。家具の無い部屋では `use` を選ばない。
- `room-use`：べっど があると `homeWithBed` が べっど のそば、無ければ `homeFor` と同じ。
- `room-fx`：光の強さ（昼・夜・消灯）、6 こまでの選び方、wiggle の 0.4 秒後に 1 に戻る、★ の組が 4 つまで。
- `revert`：版が v2.7.0、`sw.js` の `ASSETS` に新しい 2 ファイル。
